# PolyWav Merger Beta 4.0.1

## Windows

- Installer: `PolyWav_Merger_Setup_4.0.1-beta.exe`
- Portable: `polywav_merger.exe`

### What's new in 4.0.1

- Beta 4.0.1 release build
- Bundled **ffmpeg**, **sounddevice** (PortAudio), **soundfile**, and all runtime dependencies in the Windows executable
- Library: metadata field scrolling, accent palette fixes, table header corner rendering
- Playback window: waveform zoom/detail improvements, compact Notes strip, trim toolbar alignment
- Light theme: gray **Mono** accent color
- Waveform view now fits full width on open (no empty gap on the right)

### Requirements

- Windows 10/11 x64
