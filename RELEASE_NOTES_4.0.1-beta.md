# PolyWav Merger Beta 4.0.1

## Windows downloads

| File | Description |
|---|---|
| `PolyWav_Merger_Setup_4.0.1-beta.exe` | Installer (recommended) |
| `polywav_merger.exe` | Portable build |

## What's in this release

- Beta 4.0.1 build for Windows x64
- Bundled runtime: **ffmpeg**, **sounddevice** (PortAudio), **soundfile**, PySide6, numpy
- **Merge** tab: batch polywav conversion with clock-drift correction
- **Library** tab: WAV browser, BWF/iXML metadata, multichannel waveform playback, notes, trim
- Dark/light themes with accent color selection (including gray Mono in light theme)
- Waveform viewer: zoom detail, fit-to-width on open, compact Notes strip

## Requirements

- Windows 10/11 x64

macOS builds are published separately from the GitHub Actions workflow when available.
