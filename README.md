# PolyWAV Builder — Инструкция по сборке

## 📋 Что здесь находится

- **polywav_builder.py** — исходный код программы
- **polywav_icon.ico** — иконка для .exe файла и ярлыков
- **logo_48.png** — логотип для интерфейса программы
- **build_complete_installer.bat** — скрипт для полной сборки (рекомендуется)
- **build_installer.bat** — старый скрипт сборки
- **build_nsis_installer.nsi** — конфигурация для NSIS инсталлятора

---

## 🚀 Быстрый старт

### Вариант 1: Полная сборка (рекомендуется)

1. **Установите Python 3.11+** с https://python.org (галочка "Add Python to PATH")

2. **Опционально установите NSIS** для красивого установщика:
   - Загрузите с https://nsis.sourceforge.io/
   - Установите в папку по умолчанию

3. **Запустите скрипт сборки:**
   ```batch
   build_complete_installer.bat
   ```

4. **Результат:**
   - `dist/polywav_builder.exe` — портативный .exe (~100-150 MB)
   - `dist/PolyWAV_Builder_Setup.exe` — установщик (если установлен NSIS)

---

## 📦 Результаты

### ✓ polywav_builder.exe
- **Что это:** Портативный исполняемый файл, готовый к распространению
- **Размер:** 100-150 MB
- **Преимущества:**
  - Все встроено (Python, библиотеки, иконка, логотип, ffmpeg)
  - Просто скачал и запустил
  - Можно скопировать на USB флешку
- **Как использовать:**
  - Двойной клик по файлу
  - Или отправить друзьям/коллегам

### ✓ PolyWAV_Builder_Setup.exe (при наличии NSIS)
- **Что это:** Профессиональный установщик с мастером
- **Что делает:**
  - Мастер установки на русском языке
  - Выбор папки установки
  - Ярлыки в меню Пуск
  - Ярлык на рабочем столе
  - Деинсталлятор
- **Как использовать:**
  - Запустить Setup.exe
  - Следовать указаниям мастера
  - После установки найти в меню Пуск

### Опции при наличии NSIS:
Если NSIS не установлен, скрипт все равно создаст .exe файл, но установщик не будет создан. Установите NSIS и запустите скрипт еще раз.

## 🐛 Решение проблем

### "Python не найден"
- Переустановите Python с https://python.org
- **Важно:** При установке поставьте галочку "Add Python to PATH"
- После установки перезагрузитесь

### "Не удалось установить зависимости"
```batch
pip install --upgrade pip
pip install customtkinter pillow pyinstaller
```

### "ffmpeg не скачался"
- Это не критично — программа может работать без него
- Проверьте интернет соединение
- Или загрузите ffmpeg вручную с https://github.com/BtbN/ffmpeg-builds

### "NSIS не найден"
- Загрузите NSIS: https://nsis.sourceforge.io/
- Установите в папку по умолчанию
- Запустите скрипт снова

### Ошибка при запуске .exe
- Проверьте что полностью закончилась сборка (не прерывалась)
- Попробуйте запустить скрипт сборки еще раз
- Убедитесь что polywav_icon.ico и logo_48.png лежат в папке со скриптом

## 📤 Распространение

### Пользователям:
- Отправьте **polywav_builder.exe** или **PolyWAV_Builder_Setup.exe**
- Никаких дополнительных зависимостей не требуется
- Работает на Windows 7, 8, 10, 11 (64-bit)

### На сервер/облако:
- Залейте файл на гугл диск, яндекс диск, Mega и т.д.
- Или создайте релиз на GitHub

---

## 📝 Примечания

- Первая сборка может занять 5-10 минут (загрузка ffmpeg, установка пакетов)
- Последующие сборки быстрее (5-7 секунд, если не менять код)
- .exe файлы совершенно безопасны, это обычный Python код
- Иконка используется везде: на ярлыках, в меню Пуск, в установщике

---

**Если вам нужно обновить программу:**
1. Отредактируйте polywav_builder.py
2. Запустите build_complete_installer.bat
3. Получите новую версию .exe / Setup.exe
