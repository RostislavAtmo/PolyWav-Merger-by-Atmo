✨ FEATURES INCLUDED

✓ Clock Drift Offset Correction (NEW!)
  • Automatically detects and corrects timing drift
  • Precision: ±5-20ms (vs ±42ms with TC alone)
  • Works after timecode matching, independently

✓ Intelligent Alignment Window Selection
  • Scans first 25 seconds of recording
  • Finds optimal section for correlation
  • Avoids silence, room tone, pre-roll

✓ Smart Channel Mapping Dialog
  • Auto-detects transmitter types (boom, lav, etc.)
  • Proposes best recorder reference channels
  • User can manually adjust before processing
  • "No correction" option for problem files

✓ Advanced Transient Detection
  • Combines RMS energy + attack scoring
  • Finds sections with actual speaker content
  • Adaptive threshold calculation

✓ Multi-Track PolyWAV Creation
  • Combines recorder + TX wireless files
  • Preserves full BWF/iXML metadata
  • Optional 32→24-bit normalization
  • Supports multiple transmitter profiles
